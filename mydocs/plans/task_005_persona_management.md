# [수행 계획서] T005 #5: 다중 고객(Persona) 관리 기능 구현

- 작성일: 2026-05-06
- 담당: Antigravity (Gemini 3 Flash)
- 상태: 대기 (승인 전)

## 1. 개요
현재 하드코딩된 '나', '가족', '회사', '친구' 외에 사용자가 직접 새로운 관리 대상을 추가하거나, 불필요한 대상을 삭제할 수 있는 CRUD 기능을 구현합니다. 이를 통해 개인별 맞춤형 비전 관리 도구로서의 유연성을 확보합니다.

## 2. 목표
- [ ] 신규 고객 대상(Persona) 추가 기능 구현 (이름 입력 및 초기 비전 생성)
- [ ] 기존 고객 대상 삭제 기능 구현 (경고 메시지 포함)
- [ ] 탭 UI에서 추가/삭제 액션이 반영되도록 인터랙션 개선

## 3. 작업 범위
- `frontend/src/app/actions.ts`: 고객 추가/삭제를 위한 Server Actions 로직 확장
- `frontend/src/app/page.tsx`: 추가 버튼 UI 및 삭제 아이콘 적용, 상태 관리 로직 업데이트
- `frontend/src/types/vision.ts`: 필요시 데이터 구조 보완

## 4. 수행 단계
1. **1단계: 데이터 처리 로직(Server Actions) 확장**
   - `actions.ts`에 `addPersona(name: string)` 및 `deletePersona(id: string)` 함수 추가.
   - 새 Persona 생성 시 UUID 자동 부여 및 기본 비전 템플릿 설정.
2. **2단계: UI 구현 (추가 및 삭제)**
   - 탭 리스트 끝에 '+' (추가) 버튼 배치.
   - 각 탭 혹은 상세 페이지 내에 삭제 버튼 배치.
   - 이름 입력을 위한 간단한 Modal 또는 Input UI 추가.
3. **3단계: 상태 동기화 및 예외 처리**
   - 대상 삭제 시 현재 활성화된 탭이 사라질 경우의 예외 처리 (다른 탭으로 자동 이동).
   - 저장 실패 시 롤백 및 에러 메시지 표시.
