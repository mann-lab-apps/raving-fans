# [Plan] T002: 비전 수정 및 저장 기능 MVP 구현

## 1. 개요
- **타스크 ID**: T002
- **목표**: 대시보드 상에서 제공자 및 고객의 비전을 직접 수정하고 서버에 저장할 수 있는 기능을 구현한다.
- **연관 이슈**: #2

## 2. 상세 작업 단계

### Step 1: 프론트엔드 편집 UI 구현
- 비전 텍스트 옆에 '수정(Edit)' 버튼 추가
- 클릭 시 일반 텍스트가 `textarea` 입력창으로 전환되도록 상태 관리 (`isEditing` state)
- '저장' 및 '취소' 버튼 구현

### Step 2: 백엔드 API 연동 로직 작성
- 수정된 데이터를 백엔드 엔드포인트(`POST /api/visions`)로 전송하는 API 호출 함수 추가
- 저장 중(Loading) 및 저장 성공/실패 알림 처리

### Step 3: 데이터 정렬 및 갱신 로직 보완
- 저장 성공 후 백엔드에서 최신 데이터를 다시 불러와 화면 갱신
- 특정 고객의 비전만 부분 업데이트하는 것이 아니라, 전체 JSON 구조를 유지하며 업데이트

## 3. 검증 계획
- **기능 확인**: 
  1. 제공자 비전 수정 후 저장 -> 새로고침 후에도 유지되는지 확인
  2. 고객(가족/회사 등) 비전 수정 후 저장 -> 탭 전환 후에도 유지되는지 확인
- **데이터 확인**: `data/visions.json` 파일의 내용이 실제 수정된 텍스트로 변경되었는지 확인

## 4. 기대 결과물
- 사용자가 브라우저에서 직접 비전을 관리할 수 있는 완성형 MVP
- 데이터 영속성(Persistence) 확보
