# RAVING FANS (열광하는 팬)

'열광하는 팬(Raving Fans)'의 원칙을 바탕으로 서비스의 비전을 수립하고, 고객의 기대를 뛰어넘는 1%의 개선을 지속적으로 시각화하고 관리하는 도구입니다.

## 🚀 프로젝트 개요

이 프로젝트는 켄 블랜차드의 저서 '열광하는 팬'에서 제시하는 세 가지 핵심 단계를 디지털 도구로 구현합니다.
1. **나만의 비전을 결정하라**: 팀(제공자)이 지향하는 이상적인 서비스의 모습을 정의합니다.
2. **고객이 원하는 것이 무엇인지 알아내라**: 고객이 진정으로 바라는 서비스의 경험을 정의합니다.
3. **1%를 더하라**: 비전을 일치시키고, 매일 1%씩 서비스를 개선하여 열광하는 팬을 만듭니다.

## 🎯 MVP 목표: '산책' 서비스 개선

초기 MVP는 개발자 본인을 고객으로 설정하여, 일상적인 활동인 **'산책'**을 하나의 서비스로 정의하고 개선하는 것을 목표로 합니다.

### 핵심 기능
- **비전 수립 및 정렬**:
  - **이상적인 산책 (Team Vision)**: 내가 정의하는 가장 완벽한 산책의 모습 작성.
  - **바라는 산책 (Customer Vision)**: 내가 고객으로서 경험하고 싶은 산책의 니즈 작성.
  - **현재의 산책 (Current Status)**: 지금 실제로 행하고 있는 산책의 상태 기록.
- **수치화 및 시각화 (Scoring & Visualization)**:
  - **흥미/만족도 (Interest - X축)**: 다시 반복하고 싶은 정도 (0~5점).
  - **생산성/효율 (Productivity - Y축)**: 리소스 대비 가치 창출 정도 (0~5점).
  - **5x5 매트릭스**: 산책의 현재 위치를 좌표평면에 시각화하여 개선 방향 제시.
- **지속적 개선 (1% More)**:
  - 주기적인 수정 및 업데이트 기능.
  - **PWA 푸시 알림**: 리텐션을 위한 정기적인 기록 및 회고 알림.

## 📊 지표 정의

### 1. 생산성 (Productivity)
| 점수 | 기준 |
| :--- | :--- |
| 5 | 이상적인 생산성을 기록 |
| 4 | 반복적으로 효율적인 생산성을 기록 |
| 3 | 투자한 자원만큼의 생산성 |
| 2 | 과한 자원을 투자하여 일회성 가치 창출 |
| 1 | 유의미한 가치 생산 불가 |
| 0 | 아무런 가치를 생산하지 못함 |

### 2. 흥미 (Interest)
| 점수 | 기준 |
| :--- | :--- |
| 5 | 매우 즐거워 또 하고 싶음 |
| 4 | 자연스럽게 반복함 |
| 3 | 시작만 하면 괜찮은 경험 |
| 2 | 수행하기까지 많은 설득이 필요 |
| 1 | 억지로 수행 가능 |
| 0 | 다시 하고 싶지 않음 |

## 🛠 기술 스택
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (Premium Design)
- **Visualization**: Canvas / SVG 기반 커스텀 다이아그램
- **Storage**: 로컬 JSON 파일 기반 (백엔드 없는 경량 구조)
- **PWA**: Next-PWA / Service Workers & Push API
